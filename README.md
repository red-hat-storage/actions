# GitHub Actions

Reusable GitHub Actions for repository maintenance. Each action has its own README with usage and configuration details.

| Action | Description |
| --- | --- |
| [go-patch-version](go-patch-version/README.md) | Updates Go versions and dependencies across repository branches using a builder image or pinned version, then opens or refreshes a pull request for each branch. |

When adding an action, add a brief description and a link to its README in the table above.
